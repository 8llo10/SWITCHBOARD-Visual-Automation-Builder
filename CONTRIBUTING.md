# Contributing to SWITCHBOARD

## Workflow

1. Create a focused branch from `main`.
2. Keep each change scoped to one feature, fix, refactor, or documentation update.
3. Test the affected workflow or component locally.
4. Open a pull request with a clear summary and validation notes.
5. Merge only after the change is ready and any required checks pass.

## Branch naming

Use concise names such as:

- `feature/<name>`
- `fix/<name>`
- `docs/<name>`
- `refactor/<name>`

## Commit messages

Prefer short, descriptive messages such as `feat: add webhook trigger` or `fix: persist run status`.
